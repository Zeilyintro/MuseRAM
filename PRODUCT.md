# Product

## Register

product

## Users

Windows gamers and power users who want to understand memory pressure, reduce avoidable background working sets, and keep latency-sensitive applications stable while gaming.

## Product Purpose

MuseRAM is a Windows memory-management tool that monitors physical memory and process activity, previews optimization candidates, trims selected process working sets, and exposes the difference between working-set reduction and real system-available-memory change. Success means predictable behavior, clear risk boundaries, and useful control without requiring users to understand Windows internals.

## Brand Personality

Quiet, technical, trustworthy. The interface should feel like a focused desktop utility: restrained enough for repeated use, explicit about risk, and precise about what each action changes.

## Anti-references

- Marketing-style layouts, oversized headings, decorative cards, gradients, and ornamental motion.
- Interfaces that hide destructive or high-risk behavior behind vague labels.
- Raw configuration screens that expose unexplained numbers without ranges, units, validation, or reset paths.
- Inconsistent controls or low-contrast hover, light-theme, disabled, and selected states.

## Design Principles

1. Show the real system effect, not an inflated optimization number.
2. Keep normal workflows simple while progressively revealing professional controls.
3. Make protection coverage, automatic behavior, and destructive actions visible and reversible.
4. Prefer stable, familiar Windows desktop controls and consistent interaction states.
5. Preserve user settings across upgrades and keep default profiles recoverable.

## Accessibility & Inclusion

Maintain readable contrast in light and dark themes, visible keyboard focus, keyboard-operable controls, high-DPI layout stability, and complete English and Simplified Chinese resources. Do not communicate state through color alone.
